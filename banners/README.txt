Put the finished banner pictures for the home-page deck in this folder, named:

  home.png
  link.png
  parcel.png

They show in that order. .jpg and .webp with the same names also work. A missing file is skipped.
Tapping a banner asks "Book a ride, Send a parcel, or Ride with BodaLink".
Keep each file under about 300 KB: a JPEG 1400 pixels wide is plenty. You can also add banners from the Admin Adverts tab.
